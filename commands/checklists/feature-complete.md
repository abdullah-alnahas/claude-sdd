# Feature Complete Checklist

Run when claiming a feature is done. Verifies spec satisfaction and code quality.

- [ ] **Spec criteria satisfied** — Every acceptance criterion in the behavior spec has a PASS status with evidence
- [ ] **Tests pass** — Full test suite passes, including new tests for this feature
- [ ] **Review clean** — No critical or high findings from `/sdd-review`
- [ ] **No dead code** — No unused functions, variables, imports, or files introduced by this feature
- [ ] **No scope creep** — Only files related to the feature were modified
- [ ] **Documentation** — Any user-facing changes are documented (if applicable)
